 My Portfolio is a personal website showcasing the academic journey and technical interests of a CSE (AI & ML) student at MITE, Mangalore. Built with Next.js 16, TypeScript, Tailwind CSS, and shadcn/ui, it features a dark-mode-first design with emerald green accents.

The site has six main sections: an Introduction with a bio focused on LLMs, Generative AI, and software development; an Education timeline tracing the path from SSLC (89.92%) through PUC PCMC (95.17%) to current engineering studies; a Currently Learning widget showing active study areas (C, DSA, SQL, Python); a Syllabus section displaying real 1st-semester MITE coursework with credit distribution; a Matrix ASCII Rain mini project — a live canvas animation with interactive controls and a technical schematic; and a Contact section with email, GitHub, and LinkedIn cards.

The portfolio is responsive, supports light/dark theme toggling, and includes smooth-scroll navigation. A standalone HTML version and downloadable ZIP are available for easy hosting on GitHub Pages, Netlify, or Vercel.
